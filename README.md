## 📌 Project Overview

The **ARC Financial Distress Analyzer** is a machine learning-based system designed to evaluate and predict the financial distress level of companies using financial indicators.

It leverages data preprocessing, exploratory data analysis, and machine learning models to identify early warning signals of financial instability.

---

## 🎯 Objective

To build a predictive system that analyzes company financial data and classifies whether a company is at risk of financial distress using machine learning techniques.

---

## 🧠 Key Features

* 📊 Data cleaning & preprocessing
* 🔍 Exploratory Data Analysis (EDA)
* 🧮 Feature engineering on financial ratios
* 🤖 Machine learning model training & evaluation
* 📉 Financial distress prediction
* 📈 Performance evaluation using ML metrics

## 🚀 How to Run This Project

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/ARC_Financial_Distress.git
cd ARC_Financial_Distress
```

### 2️⃣ Create virtual environment (recommended)

```bash
python -m venv venv
venv\Scripts\activate   # Windows
```

### 3️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the application

```bash
python service.py
```

Or launch Jupyter notebooks:

```bash
jupyter notebook
```
